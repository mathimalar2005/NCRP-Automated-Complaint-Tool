# Automated NCRP Complaint Reading & Updating Tool

## Problem Statement
Manual processing of NCRP cyber crime complaints causes delay and high workload for police officers.

## Solution
An automated system to read, classify, and update NCRP complaints efficiently.

## Features
- Automatic complaint reading
- Crime type classification
- Status update
- Police dashboard view

## Tech Stack
- Python
- Flask / Streamlit
- MongoDB / MySQL
- VS Code

## How to Run
```bash
pip install -r requirements.txt
python app.py
